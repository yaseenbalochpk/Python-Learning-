The following roadmap represents the major Python concepts that can be practised and revisited throughout the learning journey.

Stage| Topics
"01" — Foundations| Syntax, comments, variables, data types, input and output
"02" — Operators & Logic| Operators, type conversion, conditions and Boolean logic
"03" — Iteration| "for" loops, "while" loops, ranges and nested loops
"04" — Data Structures| Strings, lists, tuples, sets and dictionaries
"05" — Functions| Parameters, arguments, return values and reusable code
"06" — Problem Solving| Logic building, exercises, debugging and edge cases
"07" — Intermediate Python| Modules, imports, exceptions and file handling
"08" — Object-Oriented Programming| Classes, objects, methods and core OOP concepts
"09" — Practical Projects| Small applications that combine multiple concepts
"10" — Next Steps| APIs, automation, libraries and further development

This roadmap is a learning reference, not a claim that every topic or stage is implemented in this repository.

💻 A First Python Example

Here is a small example of Python's readable syntax:

def introduce(name: str) -> str:
    """Return a friendly introduction."""
    return f"Hello, {name}! Welcome to Python."

user_name = input("Enter your name: ").strip()

if user_name:
    print(introduce(user_name))
else:
    print("Please enter a valid name.")

This example demonstrates a function, a string, user input, and a conditional statement.

🚀 Getting Started

Want to explore the code on your own device? Follow these steps.

1. Clone the repository

git clone https://github.com/yaseenbalochpk/Python-Learning-.git

2. Enter the project directory

cd Python-Learning-

3. Check your Python installation

python --version

If your environment uses "python3", run:

python3 --version

4. Run a Python file

python filename.py

Replace "filename.py" with the name of an actual Python file in the repository.

No computer available? You can also practise Python using a browser-based coding environment that supports Python execution.
