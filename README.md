📌 About This Repository

Welcome to my Python Learning Journey — a collection of daily Python practice files, programming exercises, and practical projects.

I'm Muhammad Yaseen, also known professionally as Yaseen Baloch, a BS Computer Science student from Pakistan.

I created this repository to document my learning, practise programming concepts, improve my logical thinking, and build a stronger foundation in software development.

Rather than keeping my learning limited to theory, I use code to experiment, solve problems, understand mistakes, and turn concepts into practical experience.

🎯 The Mission

- Strengthen Python programming fundamentals.
- Develop logical thinking and problem-solving skills.
- Practise writing, reading, testing, and debugging code.
- Organise learning through a 100-day practice journey.
- Apply programming concepts in small projects.
- Build a public record of continuous learning and improvement.

You can clone this repository and run its Python files in a local development environment.

Step 1 — Clone the repository

git clone https://github.com/yaseenbalochpk/Python-Learning-.git

Step 2 — Open the directory

cd Python-Learning-

Step 3 — Check your Python version

python --version

On some systems, use:

python3 --version

Step 4 — Run a lesson

python day1.py

Replace "day1.py" with the filename you want to practise.

Requirements: A Python 3 installation and a terminal or code editor that supports Python.

You can also use a browser-based Python environment if you do not have a computer available.

🧠 How I Learn

My approach to programming is built around active practice rather than memorisation alone.

1. Understand the concept and why it matters.
2. Write code and experiment with examples.
3. Test different inputs and expected outcomes.
4. Debug errors to understand what went wrong.
5. Practise by modifying or extending the solution.
6. Build small projects that combine multiple concepts.
7. Review previous work and identify areas for improvement.

I believe progress comes from consistent effort, curiosity, and the willingness to learn from mistakes.
